# Example Project — Willow Notes

This is fictional sample data. Willow Notes is a made-up local project for keeping a
small, source-linked collection of household plant observations. The example shows
where project purpose and decisions can live; it does not prescribe a domain model.

`project.json` contains the example identity and current goal. `DECISIONS.md` keeps a
dated decision and its reason so later contributors can understand the choice without
relying on a chat transcript.
